:doctype: article

== Governing design

Architecture authority: DESIGN.adoc, especially Sources and shutdown semantics,
Generation reload, Database lifecycle, Authentication and management, and Container delivery and Podman.
Design SHA-256 (UTF-8/LF): `c0e47905c1e242a859e390622cc7c676f7e6d6720485165cd5dd7a40512c434f`.

== Implemented candidate

* Self-contained Looprd specification and generated JSON schemas.
* Shared Python ASGI runtime, CRUD, inline handlers, authentication, WebSocket events/tickets.
* SQLAlchemy SQLite/PostgreSQL storage, explicit additive migrations, retained data.
* Sources polling, validated reload, authoritative removal, and offline restart recovery.
* GitHub AMD64/ARM64 image workflow, native container smoke, PostgreSQL CI service.
* Rootless Podman Quadlet units and installation/backup instructions.
* Existing Traefik routing for the configured API hostname and optional shared-Podman-network drop-in.
* Traefik smoke derives its hostname from deployment configuration; all published files use placeholder hostnames.
* Publication is based on the clean remote history, excluding earlier local commits containing private deployment values.
* GitHub Contents API retrieval with mounted token-file rotation and same-commit private sources.
* Separate private sources repository and ignored node-local environment configuration; node credentials stay outside Git.
* Component-local hashed API keys, explicit operation/handler/subscription scopes, and admin key management.
* Persistent key expiry/revocation and live WebSocket identity revalidation, including outstanding tickets.
* First-start management key output with retained hash, explicit CLI rotation, and mounted-token compatibility.
* Same-origin web panel for component status/reconciliation and component-key management, plus optional Traefik router.
