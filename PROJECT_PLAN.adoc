== SQLite uniqueness reflection repair

Governing section: DESIGN.adoc, Database lifecycle.
Inline uniqueness on sized string columns was enforced by SQLite but omitted by
SQLAlchemy's DDL parser, causing false schema-contract failures. Both column and
composite validation now use SQLite index metadata. Partial/expression indexes
remain insufficient for full-column uniqueness; partial named indexes are rejected.
No application-specific schema edits, constraint bypasses or fingerprint changes.
Regression coverage includes retained data/restarts, composite constraints, quoted
identifiers, weaker-index rejection and PostgreSQL partial-index enforcement.
Social's current specification and migrations passed a dry run on a temporary copy
of its installed database with this repair.
Validation: 137 local tests passed, 4 external-service tests skipped. Focused
SQLite/platform/runtime tests and fresh-package/privacy/fingerprint checks passed.
